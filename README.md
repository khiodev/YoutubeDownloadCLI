# Youtube Video Downloader CLI
Download Youtube videos as MP4 or MP3 right from your command prompt 

# Prerequisites
- v24 or above Node.js
- Python 3.9 or above (Working on using another way of downloading videos so python isn't required)

# Installation
1) Press the **code** button on top right, then download as zip
2) After downloading as a zip file extract it
3) open the "YoutubeDownloadCLI" folder and shift right click on anywhere and "Open in Terminal" or "Open in Powershell"
4) Inside the terminal or powershell run "npm i -g ." (FYI this downloads this project and sets it up)
5) Once successfully installed, Open terminal or powershell anywhere and run the command "youtubeDL" (Casing of the word isn't required)
6) Follow the instructions of the app and enjoy!
